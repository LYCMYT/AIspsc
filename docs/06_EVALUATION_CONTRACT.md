# 06｜11 类质量评估与入库

版本：rubric-v2-rebuild。属于复盘后重建方案，不是原始评测记录的逐字复原。
旧手册确有一版 11 项文字列表，但本包没有原视频、打分者、打分记录和样本统计，因此不宣称阈值已经过验证。

## 评测单元

每一个成功视频子结果单独审核；不对整批共用一个分数。
综合分为人工 1–10 整数，不是 11 项相加/平均。问题标签可以多选，但不因同一现象多标签自动重复扣分。
每个维度有 applicable=true/false；不适用须简短记录原因，不给它虚假的满分。

| ID | 维度 | 适用性与判定重点 |
|---|---|---|
| Q01 | 商品存在性 | 本任务要求展示商品时适用；没有商品要求的背景素材不得因此直接判失败 |
| Q02 | 商品一致性 | 有明确商品参考/约束时适用；颜色、结构、标识、图案、包装关键特征 |
| Q03 | 人物一致性 | 有人物时检跨帧稳定，有人物参考时另检与参考一致；无人物=N/A |
| Q04 | 人体/结构完整性 | 手指、肢体、商品物理结构与交互穿帮；不含一般轻微风格差异 |
| Q05 | 动作自然度 | 动作、速度、接触、物理运动自然；静物镜头只检查其实际运动 |
| Q06 | 时序稳定性 | 闪烁、跳变、漂移、局部结构/图案随帧变化 |
| Q07 | 画面清晰度 | 商品/主体关键细节可辨、无严重模糊/编码破损 |
| Q08 | 场景正确性 | 背景、空间关系与任务要求一致；跨帧抖动可同时标 Q06 |
| Q09 | 指令遵循度 | 是否执行 Prompt 的必要动作、展示内容、禁止项 |
| Q10 | 参考素材遵循度 | 有参考素材时适用；仅比较指定需保留的动作/构图/运镜等，不要求复制无关细节 |
| Q11 | 投流素材可用性 | 能否进入后续人工剪辑与广告素材测试；不代表平台合规审核通过，不证明转化效果 |

## 质量硬失败

H01：任务要求的商品完全缺失；H02：商品严重失真/关键商品特征错误；H03：严重人体或画面结构穿帮，影响素材使用。
只有相应任务要求适用时才触发。上述阈值先作为重建政策，真实样本校准后方可调整。

## 文件/参数技术预检（不挤占 11 项标签）

TECH_CORRUPT：文件无法解码；TECH_DURATION：时长超约定/Provider 上限；TECH_RESOLUTION：比例/尺寸错误；TECH_AUDIO：要求音频却无音轨或音轨不可用。
音频开启不等于需要口播：有口播要求时人工额外检查可听性、台词/画面同步；没有时不强制对口型。
技术预检失败不能只打高分掩盖，也不能提前把失败文件提供入库。

## 决策表

| 条件 | 审核结果 | 入库按钮 |
|---|---|---|
| 任务未成功或文件未可用 | 不允许审核 | 禁用 |
| 有技术失败或适用的硬失败 | rejected | 禁用，即使总分≥7 |
| 无硬失败且分数<7 | rejected | 禁用；至少一个问题标签及备注 |
| 无硬失败且分数≥7 | approved | 启用，需用户再次点击 |
| 已 approved 但未点击 | approved/not_saved | 不自动入库 |
| 重复点击入库 | 返回原 assetId | 不重复创建 |

保存前可编辑；保存后保留不可变审核记录。需要改判时新建 revision 并记录原因，资产仍关联相应审核版本；不会删除旧评审证据。

## 标注样本与效果数据

用固定示例演示通过/拒绝/不适用/硬失败四种情况。示例均标“重建测试样例”。
真实评测时保留 prompt、参考、模型/配置版本、输出、审核时间/人和结论；通过率只从注明窗口与分母的真实样本计算。
不把模拟生成的 20 条记录当成客户运营指标；不把审核通过率称为广告转化率。

## 图片与文案的最小审核（不冒用视频 11 维量表）

图片/文案共享“人工通过→点击入库”的状态机制，但采用 `basic-media-review-v1`：人工 passed/rejected、必填的拒绝原因、任务遵循检查、输出可读取检查。
图片检查主要商品/主体明显错误和文件可解码；文案检查非空、符合用户给定内容与长度要求，不编造未经用户提供的商品事实。
没有时序的图片、文案不要求填写 Q05/Q06，也不直接套视频总分。B1 对三种模态均要证明审核与手动入库的隔离。

## 初始评分锚点（尚未经真实样本校准）

1–3：核心要求未达成或大面积不可用；4–6：部分可用但仍需重新生成/显著修复；7–8：核心要求达成、无硬失败，可供后续人工剪辑测试；9–10：关键要求和细节稳定，仍不代表投放成效保证。
审核员先确认任务要求和适用性，再评分；不把“只有 Prompt 没有商品图”理解为天然不需要商品，商品要求可以来自 Prompt。
