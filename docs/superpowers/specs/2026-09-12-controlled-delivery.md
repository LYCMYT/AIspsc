# 受控媒体交付：范围与验收

延续已确认的下一阶段：保留 Agnes 原始结果，先处理尺寸、音轨和帧级尾差，再建立本地受控历史→审核→显式入库闭环。公开 B1 Vue / Pages 不切换真实服务。

## 媒体策略

只接受本地 MP4 常规文件（不接受符号链接、播放列表或网络 URL），最大128 MiB，单视频流、方形像素、无旋转元数据；源片最长60秒、最长边4096。输出5–15秒整数、24fps、720p/1080p、16:9/9:16/1:1、无音轨。默认等比例缩放并居中补黑边，不裁切、不拉伸，不以升采样宣称质量增强。只允许裁掉最多100ms尾差；过短视频、超长剪辑、音频保留请求明确拒绝。

原始文件只读，输入/输出分别保存 SHA-256、实际探测信息和规则版本。FFmpeg 使用参数数组、禁用网络协议、限时；结果必须全片解码、满足尺寸/SAR/帧数/时长/无音轨后才能完成。处理失败不留下可被误认成成功的 result.mp4，不覆盖已有输出目录。

## 本地验收后端

只监听127.0.0.1，单操作人；服务端独立随机访问令牌，不使用 Agnes 密钥；拒绝跨源 Origin/错误 Host/URL令牌。提供 MP4 导入、任务历史、显式后处理、11维审核、手动入库及认证下载。导入来源明确为人工导入，不冒充重新生成或客户生产数据。不可 HTTP 指定本机任意文件路径。业务审核复用 packages/domain/src/review.ts。

所有写入串行、JSON原子替换、独占进程锁、版本冲突检测。后处理任务202受理，单并发，期间可查状态；处理中断后重启标记 interrupted，不自行重做。审核绑定输出哈希；改判立即使旧资产失效；再通过仍需重新手动入库。不做账户体系、多租户、计费、充值、Provider新生成或云部署。

## 验收

原始两个真实视频哈希保持不变；输出1280×720 /120帧/5秒/无音轨。测试覆盖无授权、参数非法、重复提交、版本冲突、未审入库、硬失败覆盖高分、改判资产失效、重启持久化、坏文件和输出失败。常规CI无模型调用；独立delivery测试安装FFmpeg并生成几何夹具，不能拿夹具冒充真实模型评测。
